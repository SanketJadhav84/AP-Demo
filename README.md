# Release checklist (Git practice app)

A small web app used only to practise Git. No build step and no dependencies.

## Run it
Open `index.html` in a browser, or use the Live Server extension in VS Code.

## Files
- `index.html`: page structure
- `style.css`: styling
- `app.js`: add, complete, delete and filter tasks (saved in the browser)

## Practice ideas
- Add a "Clear completed" button (branch: `feature/clear-completed`)
- Change the accent colour in `style.css` on two branches, then merge them to see a conflict
- Fix a typo directly on `main`, then bring it into a feature branch
